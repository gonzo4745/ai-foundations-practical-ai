# AI Foundations: Practical AI for Business

A free, self-paced, no-code introduction to AI for business professionals: what AI is, how large language models work, tokens, hallucinations, prompting, agents, workflows, APIs, RAG and embeddings, safe and responsible use, key terminology, and real-world use cases.

**10 units · 15 lessons · interactive diagrams · knowledge checks after every lesson**

Created by Daniel DeSandre.

## Privacy

- No sign-up, login, name, or email.
- No analytics, cookies, trackers, or third-party scripts, fonts, or images.
- The page makes no network requests after it loads, and its Content-Security-Policy blocks outbound connections.
- Course progress and quiz results are saved only in your own browser (`localStorage`), and you can clear them any time with **Reset My Progress** on the Welcome lesson.

## Running it

It's a single static file. Open `index.html` in any modern browser, or serve the folder with any static host (e.g. GitHub Pages from the repository root).
